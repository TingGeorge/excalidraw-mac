# Vendored license texts

License texts for things the app bundles whose published package doesn't include one,
copied from their upstream sources. `scripts/third-party.mjs` uses them to write the
third-party notices.

|---|---|

| `fastdom.txt` | [wilsonpage/fastdom](https://github.com/wilsonpage/fastdom#license) (license section of the README) |
| `fuzzy.txt` | [mattyork/fuzzy](https://github.com/mattyork/fuzzy/blob/master/LICENSE-MIT) |
| `react-remove-scroll-bar.txt` | [theKashey/react-remove-scroll-bar](https://github.com/theKashey/react-remove-scroll-bar/blob/master/LICENSE) |
| `fonts/Virgil.txt` | [excalidraw/virgil](https://github.com/excalidraw/virgil/blob/main/LICENSE.md) |
| `fonts/Cascadia.txt` | [microsoft/cascadia-code](https://github.com/microsoft/cascadia-code/blob/main/LICENSE) |
| `fonts/Liberation.txt` | [liberationfonts/liberation-fonts](https://github.com/liberationfonts/liberation-fonts/blob/main/LICENSE) |
